# 🚀 AI-Moodler-Backend

Backend system built with **NestJS**, **Redis**, **TypeORM**, and **Python embedding service** for AI-driven features.

---

## 📦 Project Setup

```bash
# Install dependencies
npm install


# generate a resource
nest generate resource resource_name

# run typeorm migration
npx typeorm migration:generate -n AddExperienceTitleToFeedback

# format code with prettier
npx prettier --write .


# inside WSL
redis-cli
flushdb


Running Steps for AI Features

Start Python embedding service.

Run Redis via WSL.

Start the NestJS project.
```
